# מאקרו – מעקב חלבון, פחמימות ושומן

אפליקציית אנדרואיד אישית למעקב יומי אחרי מאקרו. בלי פרסומות, בלי חשבון ובלי אינטרנט: כל הנתונים נשמרים בטלפון.

## מה יש

- **היום:** שלוש טבעות (חלבון, פחמימות, שומן) מול היעד, ופס קלוריות שמפוצל לפי מקור (חלבון ×4, פחמימות ×4, שומן ×9).
  כפתור "הוסף" מוסיף כמויות בגרמים. לחיצה על שורה ברשימה פותחת עריכה או מחיקה. החצים בכותרת עוברים בין ימים.
- **היסטוריה:** גרף עמודות לשבוע, חודש, 3 חודשים (ממוצע שבועי) או שנה (ממוצע חודשי), לכל מדד, עם קו יעד, ממוצע יומי ומספר הימים שעמדו ביעד.
- **הגדרות:** יעד לכל מדד – ללא, מינימום, מקסימום או טווח. יעד חדש חל מהיום והלאה, וימים קודמים נמדדים מול היעד שהיה אז.
  ייצוא וייבוא גיבוי לקובץ JSON.

## התקנה

מ-[Releases](../../releases/latest) מורידים את `MacroTracker.apk` לטלפון ופותחים אותו.
(בפעם הראשונה אנדרואיד יבקש לאשר התקנה ממקור לא ידוע.) גרסה חדשה מותקנת מעל הישנה והנתונים נשמרים.

## בנייה

כל push ל-`main` בונה APK ב-GitHub Actions (`.github/workflows/build.yml`) ומעדכן את ה-release `latest`.
